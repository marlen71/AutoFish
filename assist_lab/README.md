# Assist Lab — отдельный ресурс для своего FiveM-сервера

Первая тестовая реализация на Lua + NUI. **Не новая версия Python Assist и не EXE**.
Использует игровые natives: координаты, кости, камеру, проекцию на экран и LOS.
YOLO, .pt, Python и CUDA для этого ресурса не нужны. Текущие Assist и FishMod
не изменяются. Ресурс не предназначен для GTA Online, RMRP или стороннего сервера.
Работа на FiveM не означает совместимости или обнаруживаемости на другом клиенте.

## Что потребуется

- Официальный FiveM и поддерживаемая им установка GTA V.
- Свой изолированный FXServer с работающим игровым режимом/spawn персонажа.
- Доступ к `resources/`, `server.cfg` и консоли этого сервера.
- Согласие участников теста; по умолчанию игроки вообще не являются целями.

Сам ресурс сервер не устанавливает. Официальная инструкция FXServer:
https://docs.fivem.net/docs/server-manual/setting-up-a-server/
Нельзя просто скопировать ресурс в папку RMRP или запустить его на чужом сервере.
Код не читает память процесса, не загружает сторонние DLL и не обходит античит.

## Установка

1. Распакуйте архив **AssistLab-FiveM.zip**. Скопируйте папку `assist_lab`
   в `resources/[local]/assist_lab` своего FXServer. `fxmanifest.lua` должен
   находиться непосредственно внутри этой папки, без лишней вложенности.
2. Добавьте настройки из `server.cfg.example` в свой server.cfg:

   ```cfg
   set assist_lab_enabled 1
   set assist_lab_players 0
   add_ace identifier.license:YOUR_TEST_LICENSE assist.lab allow
   ensure assist_lab
   ```

   Замените `YOUR_TEST_LICENSE` идентификатором своего тестового аккаунта из
   администрирования сервера (часть после `license:`). Не публикуйте его в чате.
   Если уже есть тестовая админ-группа, можно дать `assist.lab` именно ей.
   Не выдавайте разрешение `builtin.everyone` на публичном сервере.
3. Перезапустите сервер или выполните `refresh`, затем `ensure assist_lab`
   в серверной консоли после установки convars/ACE.
4. Подключитесь к своему серверу и заспавньте персонажа. Нажмите **Insert**
   или введите `/assistlab`. При отказе сервер печатает access denied:
   проверьте convar и ACE, а не пытайтесь обходить их.

Ресурс выключен без `assist_lab_enabled=1`. ACE проверяется сервером при выдаче
доступа и каждые 2 секунды после этого. Отзыв разрешения выключает помощь и удаляет
созданных NPC. Это штатные ограничения тестового ресурса, **не защита от клиента,
который уже выполняет произвольный модифицированный Lua-код**.

## Первый тест

1. Откройте меню на открытом свободном участке карты. Нажмите **«Создать 3 NPC»**.
   Перед персонажем создаются два стоящих и один гуляющий локальный NPC. Загрузка
   модели может занять до 5 секунд. NPC не сетевые и не видны другим клиентам;
   они неуязвимы, чтобы можно было повторять тесты. На неподходящей поверхности
   размещение может быть некорректным. Повторная кнопка заменяет предыдущую тройку.
2. Выберите голову/туловище, режим `rmb` или `auto`, FOV и smooth.
   Помощь и триггер по умолчанию выключены. Настройки действуют после **«Применить»**.
3. Явно включите общий master кнопкой или **F6** после закрытия меню.
   Открытое меню всегда приостанавливает помощь. Возьмите оружие обычным способом:
   ресурс оружие и патроны не выдаёт.
4. В режиме `rmb` удерживайте ПКМ. В `auto` поворот камеры разрешён без ПКМ,
   но только при включённом AIM, master ON, вооружённом/живом персонаже,
   закрытом меню/паузе и видимой цели в FOV. Во время перезарядки не действует.
5. Триггер включайте отдельно. Он подаёт короткий `INPUT_ATTACK` через
   `SetControlNormal`, а не создаёт пули и не подтверждает попадания. Нужны
   та же активация, точка под прицелом, центр экрана внутри бокса, задержка
   на одной цели и интервал. Ручное нажатие атаки не запускает новый импульс.
   Поведение INPUT_ATTACK зависит от оружия и ресурсов сервера; нужно проверить
   на вашей сборке FiveM. Постоянно зажатая системная кнопка мыши не создаётся.

## Управление и журнал

- **Insert** / `/assistlab` — меню; **Esc** — закрыть меню.
- **F6** — общий master ON/OFF (F8 не используется: это консоль FiveM).
- **F7** — auto / ПКМ.
- **F9** — триггер ON/OFF.
- **F10** / `/assistlab_stop` — аварийный стоп, также выключает AIM и триггер.
  F10 обрабатывается и в NUI-меню. Перед сворачиванием/Alt+Tab используйте стоп:
  отдельной проверки фокуса окна ОС в этой версии нет.

Привязки доступны в настройках клавиатуры FiveM. Настройки текущей версии живут
только в памяти сессии: после перезапуска ресурса master, AIM и триггер выключены.

Внизу меню есть журнал последних 200 событий: доступ, настройки, выбранные цели,
импульсы атаки, создание NPC и стоп. Откройте раздел, нажмите «Обновить журнал»,
скопируйте JSON из поля. Событие trigger_pulse означает запрос ввода, **не выстрел
или попадание**. Журнал сам не отправляется наружу и не пишется в файл; при остановке
ресурса исчезает. Сервер пишет только события выдачи доступа в свою консоль.

## Боксы, видимость и дальность

- Исключение своего — по entity ID, а не по скину.
- Голова/туловище — координаты костей 31086 / 24818, не доля YOLO-бокса.
- Бокс — проекция восьми углов model dimensions. Это не точная рамка текущей
  анимации; на краях экрана при непроецируемом угле рамка может не рисоваться.
- Цели берутся только на экране, в заданной мировой дистанции (10..300 м),
  с `HasEntityClearLosToEntity(...,17)`. LOS — проверка игрового движка между
  персонажами, не попиксельная проверка видимости из камеры; углы/частичные
  перекрытия могут давать отличия. Скрытые цели специально не показываются.
- Положение считается каждый игровой кадр, без очереди нейросети. Это не обещание
  отсутствия задержек: FPS игры, ресурсы сервера и стриминг всё равно влияют.
- FOV — радиус в физических пикселях вокруг предполагаемого прицела в центре
  экрана. Модифицированный прицел/камера могут потребовать адаптации.
- По умолчанию рассматриваются **только созданные ресурсом NPC**. Для теста с
  согласившимися игроками своего сервера администратор должен явно включить
  `set assist_lab_players 1`, после чего в меню разрешается соответствующий флажок.
  Доступны только застримленные клиенту активные игроки. Команды не распознаются.

## Остановка и удаление

В серверной консоли `stop assist_lab` останавливает ресурс и удаляет созданных
локальных NPC, снимает NUI-фокус. Или `set assist_lab_enabled 0`: доступ будет
отозван на очередной проверке (до 2 секунд). Для удаления уберите `ensure assist_lab`
и папку ресурса. Пользовательские/сетевые персонажи не удаляются.

## Проверки

```sh
lua assist_lab/tests.lua
node --check assist_lab/web/app.js
```

Тесты содержат чистую геометрию, валидацию, блокировку целей и smoke-проверку
клиентских callbacks с заглушками natives. Код Lua синтаксически проверен парсером
Lua 5.3 и выполнялся в Fengari; это **не запуск в GTA/FiveM**. NUI, camera natives,
LOS, стрельба и жизненный цикл NPC требуют ручного теста на FXServer. Полноценная
проверка реакции готового античита ещё не проводилась. Чужие loader/бинарники и
исходники найденных читов не использованы.
