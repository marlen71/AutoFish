# Eternal Core — release v1.0.0

Лоадер игр и макросов для Windows и отдельный сервер с веб-панелью. Сервер и клиент поставляются раздельными архивами.

## Новое

- **Один вход администратора:** данные сайта подходят для лоадера без создания второго аккаунта. Новый UID администратора не получает подписку автоматически.
- **Ключи подписок:** администратор выбирает продукт, срок подписки, конечную дату активации, число разных пользователей, общее число активаций и число использований на одного человека. Пользователь активирует ключ в профиле. Каждая активация продлевает срок; конкурирующие запросы учитываются атомарно. Полный ключ показывается только при создании.
- **Смена пароля в профиле** со старым паролем и подтверждением нового. Пароль администратора единый для сайта и лоадера; другие сеансы завершаются.
- Новый дизайн, логотип и значок **Eternal Core**; кнопка «Тех. Поддержка» при входе и в профиле открывает https://discord.gg/jVKudmmBbA.
- Лоадер по умолчанию подключается к `192.168.0.105:8765`; адрес не отображается в интерфейсе. Сохранены выбор игр и собственных макросов, управление пользователями/подписками/HWID, встроенный RMFish и аварийная остановка.

## Важные ограничения

**Выбран HTTP только в локальной сети: логины, пароли, токены и ключи передаются без шифрования.** Серверный адрес должен быть назначен серверному компьютеру. Не открывайте порт в интернет, ограничьте доступ брандмауэром; публичный доступ требует HTTPS. Адрес в лоадере не показан, но не является секретом.

Перед обновлением остановите сервер и сделайте резервную копию базы. Миграция сохраняет старые UID, подписки, устройства и сессии. Если у старого пользователя и администратора совпадает логин, аккаунты автоматически не объединяются; для однозначного входа переименуйте старого пользователя по UID в панели. Подробности и порядок установки — в `README-SERVER.md` серверного архива, использование лоадера и аварийная остановка — в `INSTRUCTIONS.txt` клиентского архива.

Запуск новых макросов требует реализации в лоадере; сейчас реально запускается только встроенный RMFish. Это не защищённая от модификации DRM. Настоящая GTA5/RMRP и физические клавиши не проверены: перед рыбалкой проверьте F10 в игре и не запускайте бота, если остановка не работает. Не оставляйте программу без присмотра.
