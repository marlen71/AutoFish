# Серверное исправление Eternal Core 1.3.0: Windows ACL

Исправляет ошибку `SeSecurityPrivilege` при настройке HTTPS на Windows, не ослабляя защиту ключей. Существующие база, сертификаты и клиент не заменяются. Это **только серверный патч**, а не новая версия клиентского EXE.

## Установка

1. Остановите сервер и сохраните защищённую копию папки `data`.
2. Скачайте `EternalCore-Internet-ACL-Hotfix-v1.zip`. Скопируйте из архива **только `internet_gateway.py`** в установленную папку сервера рядом с `CONFIGURE-INTERNET.bat`, подтвердив замену.
3. Повторно запустите `CONFIGURE-INTERNET.bat`, укажите публичный IPv4 и уже скачанный исходный `EternalCore.exe` 1.3.0. Исходный EXE заново скачивать не нужно.
4. После успешной настройки запустите `START-INTERNET.bat`. При первой настройке раздайте созданную копию клиента по проверенному защищённому каналу. Если совместимый клиент уже настроен с тем же корнем и IP, его менять не требуется.

Не удаляйте `data` и закрытые ключи. Если появится сообщение о неполных данных сертификата, сохраните их и обратитесь за помощью; не создавайте новый корень самостоятельно. Локальные ACL не защищают облачную копию OneDrive. Для HTTPS необходим доступный извне TCP 8765; Let's Encrypt и порт 80 не нужны.
