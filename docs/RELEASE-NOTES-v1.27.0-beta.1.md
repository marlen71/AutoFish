## RMFish 1.27.0-beta.1 — EXE с графическим меню

Предварительная версия новой визуальной программы для рыбалки в RMRP/GTA5. **На Windows и в настоящей игре она ещё не проверена**; использование и совместимость зависят от версии интерфейса и настроек игры. Проверьте правила сервера, не оставляйте программу без присмотра.

### Скачать и запустить

1. Скачайте **`RMFish-v1.27.0-beta.1-Windows.zip`** из Assets и распакуйте в папку с правом записи.
2. Запустите **`RMFish.exe`**. Нужны Windows 10/11 и .NET Framework 4.5 или новее; устанавливать Python или сторонние библиотеки не требуется. EXE не подписан цифровым сертификатом, поэтому Windows может предупредить о неизвестном издателе.
3. В игре вручную выберите удочку и наживку, нажмите в RMFish «Старт» или **F8** и вернитесь в GTA5. Рекомендуется оконный режим без рамки и 1920×1080.
4. Остановка: **F8**, **F10**, кнопка «Стоп» или **`STOP.bat`**, который находится в архиве рядом с EXE. **F9** проверяет распознавание без кликов. Подробная инструкция вложена в архив.

### Что умеет и чего не умеет

- Визуально определяет шкалы заброса и вываживания, отправляет ЛКМ и приостанавливает клики, когда окно процесса `GTA5.exe` не активно. Память игры не используется.
- Инвентарь, удочку и наживку необходимо подготовить **вручную**. Если игра не показывает новый заброс после вываживания, его тоже необходимо начать вручную. Наличие наживки и успешная поимка не проверяются.
- В отличие от предыдущего стабильного **v1.26.0**, новая версия **не содержит AI-детектор и автоматическое управление инвентарём**. Стабильный релиз остаётся доступен; это не бесшовное обновление всех его возможностей.
- Исходный запуск через `RMFish.bat` сохранён в исходном коде релиза. Для него необходима полная структура репозитория и Windows PowerShell 5.1.

### Проверка

Автоматические тесты распознавания на предоставленных скриншотах и синтетических данных, переходов состояний и остановки прошли. EXE собран кросс-компилятором для .NET Framework и запущен в тестовой среде Mono/Xvfb с имитацией Windows API. **Это не проверка запуска на Windows, сценария сборки Windows PowerShell, горячих клавиш или взаимодействия с реальной GTA5/RMRP.**

SHA-256 для ZIP и отдельного EXE приведён в `SHA256SUMS.txt` среди файлов релиза.
