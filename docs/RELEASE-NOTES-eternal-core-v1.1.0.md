# Eternal Core 1.1.0

Новая сборка лоадера со встроенным RMFish. Старый сервер, его база и Python не требуют обновления.

## Как установить

1. Закройте предыдущий лоадер и сохраните резервную копию его EXE. Скачайте `EternalCore-v1.1.0-Windows.zip`, распакуйте весь архив в доступную для записи папку и запустите `SETUP-ETERNAL-CORE.bat`. Он проверит .NET Framework 4.5+ и предложит установить .NET 4.8 от Microsoft при необходимости. Установка может запросить права администратора и перезагрузку. Встроенному RMFish не требуются Python, pip или отдельные библиотеки.
2. Если администратор прежде менял встроенные настройки подключения, он должен заново настроить **новый** EXE прежним серверным `CONFIGURE-LOADER.bat` и положить результат под именем `EternalCore.exe`. Для стандартной настройки этого не требуется. Не заменяйте сервер или его базу.
3. Eternal Core 1.0.0 ещё не умеет самообновляться, поэтому этот первый переход нужно выполнить вручную. Впоследствии 1.1.0 проверяет стабильные релизы этого репозитория при запуске; кнопка «Обновления» выполняет проверку вручную. Установка происходит только с вашего согласия и только после закрытия RMFish.

При обновлении загружается только `EternalCore.exe`, включая встроенный RMFish. Размер и SHA-256 сверяются с GitHub API, настройки подключения переносятся из старого EXE, а сессия и другие файлы не изменяются. После замены проверяется запуск окна; при ошибке предпринимается откат. Предыдущий EXE сохраняется как `previous.exe` во временной папке `.eternal-core-update-…`. Приложение не имеет цифровой подписи; доверие основано на GitHub/TLS и проверке опубликованного SHA-256. Доступ к GitHub нужен только для проверки и загрузки обновлений.

## Рыбалка и автоотход

- Исправлены определение шкалы на другой высоте и переход к следующему забросу после вываживания. Сообщение о тайм-ауте больше не утверждает, что наживка закончилась: программа не проверяет её наличие.
- Экспериментальный автоотход **выключен по умолчанию**. В RMFish откройте «Настройки» → «Автоотход…»: нужно записать по F9 реальное сообщение об окончании рыбы над миникартой и три элемента инвентаря — удочку, «Ловить рыбу», «Хлебный мякиш». F10 отменяет запись. Не записывайте вместо него обычное «Забросьте удочку».
- При совпадении обученного сообщения программа один раз нажимает пробел, идёт S 7 секунд, затем W 7 секунд, открывает инвентарь и проверяет элементы перед записанными кликами. При потере фокуса, стопе или несовпадении экрана маршрут прерывается. Из-за препятствий, камеры и скорости движения точный возврат не гарантирован. Образцы хранятся локально.

## Важно

GTA5/RMRP, настоящее уведомление об исчерпании рыбы, приём программных клавиш и физические аварийные клавиши ещё **не проверялись**. В безопасном месте сначала проверьте F10 при активной игре и не оставляйте программу без присмотра. Доступные резервные методы остановки описаны в `INSTRUCTIONS.txt`. Возможны ложные совпадения изображения и пропуски. Соблюдайте правила сервера.

Windows CI проверяет сборку и интерфейс, синтетические F9/F10, установщик в режиме без загрузки, выбор релиза, сохранение настроек, замену EXE и откат, а также серверные тесты. Интерактивная установка .NET, UAC и поведение в самой игре не тестировались. Сервер HTTP в LAN не шифрует пароли, токены и ключи; не открывайте его в интернет.
