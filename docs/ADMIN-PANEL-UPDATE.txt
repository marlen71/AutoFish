Eternal Core — исправление входа в панель при обновлении страницы

Этот архив предназначен только владельцу сервера. Он не изменяет базу, лоадер или серверную программу.

1. Остановите запущенный сервер. На всякий случай сохраните копии папки data и текущего файла static\app.js.
2. Распакуйте этот архив во временную отдельную папку. Скопируйте только файл static\app.js из архива в папку static существующего сервера, подтвердив замену. Не заменяйте папку data и остальные файлы сервера.
3. Запустите сервер и откройте панель. Войдите один раз; после обновления страницы в той же вкладке вход восстановится, пока серверная сессия действительна (до 12 часов).

Пароль веб-приложение не сохраняет. Токен сессии находится в sessionStorage вкладки и доступен скриптам того же сайта. На общем компьютере нажимайте «Выйти». Если сервер недоступен при выходе, локальный токен удалится, но серверная сессия может действовать до окончания срока. HTTP в LAN не шифрует передаваемые пароль и токен. Автообновление лоадера не меняет сайт автоматически.
