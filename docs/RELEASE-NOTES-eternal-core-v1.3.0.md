# Eternal Core 1.3.0

Интернет-шлюз создаёт собственный внутренний TLS-сертификат автоматически: домен, Let's Encrypt и порт 80 не требуются. Админ-панель остаётся доступной только на серверном ПК. Из интернета к серверу должны доходить TCP 8765 и ответы по этому соединению; бэкенд 18765 наружу не открывайте.

## Если сервер уже установлен

1. Временно отключите старый публичный HTTP, выполните `BACKUP.bat`, остановите сервер и сохраните копию `data` и старого `server.py`.
2. Из `EternalCore-Internet-Update-v1.3.0.zip` замените только `server.py` и положите рядом `internet_gateway.py`, `CONFIGURE-INTERNET.bat`, `START-INTERNET.bat`. Базу, `data`, `static` и другие файлы не заменяйте. Подробности находятся в `INSTRUCTIONS.txt` патча.
3. Распакуйте новый клиентский ZIP, запустите `CONFIGURE-INTERNET.bat` на остановленном сервере, укажите публичный IPv4 и новый EXE. Скрипт с согласия владельца скачает Caddy с проверкой SHA-256, создаст внутренний CA и настроенную копию EXE.
4. Замените EXE в копии клиентского комплекта этой настроенной копией и **один раз раздайте её людям** по проверенному защищённому каналу. Настроенный EXE не подписан цифровой подписью. Старые клиенты не знают новый корень и не перенастраиваются автоматически.
5. Направьте внешний TCP 8765 на серверный ПК и запустите `START-INTERNET.bat`. На серверном ПК панель: `http://127.0.0.1:18765/admin/`. Проверьте вход новым EXE из другой сети. Браузер внутреннему сертификату не доверяет; не отключайте проверку TLS.
6. Остановив сервер, сделайте отдельную защищённую копию `data/internet-gateway`. `BACKUP.bat` сохраняет базу, но не закрытые TLS-ключи. Не распространяйте серверные файлы, базу, копии или ключи. OneDrive может синхронизировать эти ключи в облако.

Повторная настройка сохраняет корень. При потере или повреждении его нужно восстановить из копии; замена корня или IP требует повторной раздачи клиента. Корневой сертификат имеет конечный срок и не продлевается автоматически в Caddy 2.11.9. Лоадер проверяет имя/IP, срок и цепочку сертификата и закреплённый корень без установки его в Windows. При обновлении поддерживающего эту схему лоадера адрес и корень сохраняются; встроенный RMFish обновляется вместе с EXE. Новая запись в каталоге сама по себе не доставляет новый продукт.

Исправлен отдельный сбой серверного логгера при таймауте соединения до получения HTTP-запроса. Доступность внешнего порта зависит от роутера, брандмауэра, публичного IP и провайдера и должна проверяться владельцем из другой сети. Обновление лоадера не обновляет сервер; данная версия не проходила независимый аудит безопасности.
