Eternal Core 1.3.0 — серверное исправление Windows ACL

Это исправление устраняет ошибку SeSecurityPrivilege при настройке интернет-шлюза. Оно меняет только серверный скрипт. Клиент EternalCore.exe версии 1.3.0 и его сертификат совместимы: скачивать новую версию клиента не требуется.

Как установить на уже настроенный сервер 1.3.0:
1. Остановите сервер и закройте окно CONFIGURE-INTERNET.bat. Сохраните защищённую копию папки data; база и ключи в ней конфиденциальны.
2. Скопируйте internet_gateway.py из этого архива в папку сервера рядом с CONFIGURE-INTERNET.bat, подтвердив замену одноимённого файла. Больше ничего из сервера не удаляйте и не заменяйте.
3. Запустите CONFIGURE-INTERNET.bat повторно, укажите публичный IPv4 и тот же путь к распакованному исходному EternalCore.exe 1.3.0. Скачанный ранее архив Caddy будет повторно использован при совпадении SHA-256.
4. После сообщения «Готово» используйте путь к настроенному EXE, показанный в окне, и запустите START-INTERNET.bat. При первой настройке раздайте настроенную копию клиента по проверенному защищённому каналу. Если совместимый клиент уже настроен с тем же сертификатом и IP, повторная раздача не нужна.

Если появится сообщение о неполных или повреждённых данных сертификата, ничего не удаляйте и не создавайте новый корень вручную: сохраните папку data и обратитесь за помощью. Замена корня потребовала бы повторной раздачи клиентов.

Скрипт ограничивает доступ к ключам учётной записью владельца, SYSTEM и локальными администраторами. Локальные разрешения Windows не защищают облачную копию в OneDrive. Не распространяйте папку data, базу и закрытые ключи. HTTPS использует TCP 8765, порт 80 и Let's Encrypt не нужны. Доступ из другой сети зависит от роутера, брандмауэра и провайдера и проверяется отдельно.
