RMFish 1.27.0-beta.1 — предварительная версия

Важно: EXE собран и открыл меню на Windows Server 2022 в CI, но работа с настоящей GTA5/RMRP, горячие клавиши и игровой ввод на реальном ПК ещё не проверены. Это новая визуальная реализация: AI-распознавания и автоматического управления инвентарём из прежней версии 1.26.0 здесь нет. Проверьте правила сервера — автоматизация может быть запрещена.

Системные требования: Windows 10/11 и .NET Framework 4.5 или новее (обычно уже входит в Windows). Python, PowerShell и установка сторонних библиотек для запуска EXE не требуются. Файл RMFish.exe не подписан цифровым сертификатом, поэтому Windows может предупредить о неизвестном издателе.

ЗАПУСК

1. Распакуйте весь ZIP в доступную для записи папку, например на рабочем столе. Не запускайте программу внутри архива. STOP.bat должен находиться рядом с RMFish.exe.
2. Запустите GTA5/RMRP. Выберите оконный режим без рамки, соотношение 16:9, лучше 1920×1080; клиентская область окна должна быть не меньше 1280×720 и целиком видна на экране.
3. В зоне рыбалки вручную нажмите I (Ш), выберите бамбуковую удочку, «Ловить рыбу» и «Хлебный мякиш». Программа не открывает инвентарь и не выбирает предметы самостоятельно.
4. Запустите RMFish.exe двойным щелчком, нажмите «Старт» и вернитесь в игру. F8 тоже запускает и останавливает работу.
5. Чтобы остановить работу, нажмите F8, F10, кнопку «Стоп» или запустите STOP.bat. Горячие клавиши могут быть заняты другой программой — в этом случае используйте кнопку или STOP.bat. Для нового запуска нажмите «Старт»/F8: программа удалит старый STOP.txt.

ПРОВЕРКА И ОГРАНИЧЕНИЯ

F9 проверяет распознавание без кликов, пока окно GTA5 в фокусе; результат выводится на странице «Диагностика». Там же доступна проверка через три секунды. При потере фокуса программа приостанавливает клики и продолжает при возвращении в игру. При закрытии RMFish работа прекращается.

RMFish ориентируется на изображение шкал и не читает память игры. Изменённый интерфейс, перекрытое окно, масштаб HUD, эксклюзивный полноэкранный режим или блокировка синтетических кликов могут помешать работе. Если игра запущена с правами администратора, попробуйте запустить RMFish с теми же правами; успех не гарантируется.

Если после вываживания игра не показывает следующую шкалу заброса автоматически, подготовьте следующий заброс вручную. Наличие наживки и фактическая поимка не проверяются; счётчики показывают только завершённые фазы. Не оставляйте бета-версию без присмотра.
