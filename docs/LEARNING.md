# От твоей игры — к ИИ-боту: запись → датасет → обучение → модель

v1.25. План простой: бот записывает, КАК ТЫ играешь, превращает это в датасет,
ты обучаешь на нём модель, кладёшь её боту — и бот начинает видеть игру твоими
глазами. Всё локально, без облака.

## Как это работает (честно)

Твои действия — готовые метки. Каждый твой клик рекордер фиксирует ВМЕСТЕ с
кадром и координатой: «вот здесь человек кликнул» — это пример объекта для
модели (удочка, строка меню, кнопка). Экспортёр сам вырезает эти места и
раскладывает по формату YOLO. Дальше — стандартное обучение на твоей машине.

## Шаг 1. Запиши свою игру (2–10 минут)

1. Открой страницу **«AI-ЗРЕНИЕ»** → кнопка **«⏺ Записать сессию»**.
2. Играй руками КАК ОБЫЧНО: открой инвентарь, кликни удочку, «Использовать»,
   поиграй мини-игрой, поймай пару рыб. Чем разнообразнее сцены — тем лучше
   (день/ночь, разные места).
3. Нажми **«⏹ Остановить запись»** (или она остановится сама по лимиту МБ).
   Сессия ляжет в `sessions/rec_ГГГГММДД_ЧЧММСС/`: кадры (`frames/`), твои
   клики/клавиши (`actions.jsonl`), разбор мини-игры с твоей ЛКМ
   (`imitation.jsonl`), итоги (`meta.json`).

Пока рекордер пишет — бот НЕ управляет игрой вообще: он только наблюдатель.
Рекомендуется 2–4 сессии по 3–5 минут: отдельно инвентарь/меню, отдельно рыбалка.

## Шаг 2. Собери датасет

Кнопка **«Собрать датасет»** на той же странице (или `python scripts/export_dataset.py`):

```
Кадров: 1500 | кликов-меток: 42 | объектов: 42 | фон: 350 → dataset_out/
```

* `images/train`, `images/val` + `labels/...` — кадры и YOLO-метки;
* твой каждый клик → вырезанный объект с классом-эвристикой:
  `menu_row` (красная строка меню), `inventory_item` (левая панель),
  `click_target` (всё остальное);
* кадры без кликов идут «фоном» с пустыми метками (модель учится видеть, где
  объектов НЕТ);
* **`review.csv`** — таблица «файл;кадр;x;y;класс»: открой и поправь классы
  там, где эвристика ошиблась (это 5 минут, зато метки честные).

## Шаг 3. Обучи модель (один раз, на своей машине)

```bash
pip install ultralytics
yolo detect train data=dataset_out/data.yaml model=yolov8n.pt imgsz=640 epochs=80
```

CPU потянет (часы); с видеокартой — минуты. Получишь `best.pt`.

## Шаг 4. Экспорт в ONNX и подключение к боту

1. Экспортируй в ONNX и прогони постобработку под контракт бота (`nms5`):
   выход `[1, M, 5+C]`, строка = `cx, cy, w, h, obj, class…` после sigmoid,
   координаты в долях входа (см. datasets/README.md §5).
2. Положи `rod_detector.onnx` в `ai/models/`, впиши в `manifest.json`
   (имя файла, sha256, классы В ТОМ ЖЕ ПОРЯДКЕ, что при обучении).
3. На странице «AI-ЗРЕНИЕ»: режим **«AI (ONNX)»** или **«Гибрид»** →
   «Перезапустить AI». Статус должен стать «работает».

С этого момента поиск удочки при экипировке идёт НЕЙРОСЕТЬЮ, обученной на
твоих же кликах. Шаблоны остаются страховкой (фолбэк автоматический).

## Путь к «чистому ИИ-боту» (этапы)

| Этап | Что даёт | Статус |
|---|---|---|
| 1. Запись сессий | датасет из твоей игры | **v1.25 — готово** |
| 2. Детектор объектов | бот видит удочку/меню/предметы нейросетью | после твоего обучения (шаги 3–4) |
| 3. Имитация мини-игры | `imitation.jsonl`: зона/рыба/срыв + твоя ЛКМ | **v1.25 — собирается**, политика обучается позже |
| 4. Политика действий | модель решает «держать/отпустить» вместо реле | после набора имитационных данных |
| 5. Полный ИИ-бот | зрение + политика без шаблонов | этапы 2+4 |

Бот НЕ станет «чистым ИИ» в один клик — и я не буду притворяться обратным:
нужны твои записи (шаг 1) и одно обучение (шаг 3). Зато каждый следующий этап
требует только новых файлов-моделей, без переписывания бота: архитектура
(`ai/` + манифест + режимы legacy/ai/hybrid) уже это умеет.

## Ограничения и безопасность

* Рекордер пишет ТОЛЬКО экран и твои клики/клавиши в свою папку — ничего не
  отправляет и не выполняет; лимит объёма (по умолчанию 500 МБ на сессию).
* Клавиши пишутся только на время записи (нужны для датасета «что ты жал и
  когда»: TAB, G, …) — выключается ключом `ai_rec_keys`.
* Неизвестные сцены (снапшоты `game.unknown_visual_change`) — дополнительный
  материал: то, чего бот не понял, попадает в `diagnostics/snapshots/`.
* Конфиденциальность: кадры экрана — это и чат, и браузер. Записывай в моменты,
  когда на экране только игра.
