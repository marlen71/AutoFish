# RMFish Product 1.30.0

Модуль для Eternal Core 1.4.0 и совместимых лоадеров с независимым обновлением продуктов. Эта версия встроена в Eternal Core 1.4.0; более старый стабильный лоадер 1.3.0 отдельные модули не загружает и сначала должен обновиться.

- Экспериментальный автоотход можно настроить по F9 или по полным, необрезанным скриншотам игры: отдельные состояния для удочки, «Ловить рыбу», хлеба или червя и точное уведомление об окончании рыбы. Клик выполняется только при совпадении небольшого сохранённого образца и активном окне игры.
- Для маршрута нужно проверить и подтвердить поворот на 180°; программа идёт W 7 секунд после каждого из двух поворотов. Возврат не гарантирован. Фокус, остановка или несовпадение элемента прерывают маршрут.
- Автоотход выключен по умолчанию; режим свёрнутой GTA и распознавание звука не реализованы. Реальная GTA5/RMRP и маршрут не проверялись. Проверьте F10 и сначала испытайте под наблюдением на безопасном месте.

Встроенная версия 1.30.0 уже содержит тот же функционал; отдельный DLL устанавливается автоматически только лоадером с более старой встроенной/установленной версией, после проверок GitHub и успешного открытия окна. Модуль не подписан цифровой подписью.
