# Eternal Core 1.2.0 — HTTPS для подключения из другой сети

## Важно: обновление не настраивает сеть автоматически

Лоадер по умолчанию настроен на LAN и из другого интернета его частный адрес не доступен. Версия 1.2.0 добавляет опциональный HTTPS-шлюз для публичного IPv4, подробные сообщения о сетевых и TLS-ошибках и ручной серверный патч `EternalCore-Internet-Update-v1.2.0.zip`. Лоадер не показывает адрес в интерфейсе.

Для существующего сервера: сделайте резервную копию базы, остановите сервер, установите **только** файлы из отдельного серверного патча и следуйте `INSTRUCTIONS.txt` внутри него. `data` и `static` не заменяются. `CONFIGURE-INTERNET.bat` по запросу загружает официальный Caddy 2.11.9 с GitHub и сверяет закреплённый SHA-256; `START-INTERNET.bat` запускает локальный Python-сервер и HTTPS-шлюз. Нужны внешний TCP 8765 и TCP 80 для получения и обновления сертификата Let's Encrypt. Админ-панель доступна на серверном ПК через loopback, а публичный шлюз пропускает только API лоадера. Автообновление не меняет сервер, сеть или другие компоненты.

Владелец должен **один раз раздать пользователям заново настроенный EXE** вместе с остальными файлами клиентского архива: предыдущие копии и автообновление сохраняют старый адрес. Токен со старого адреса новому серверу не передаётся, понадобится новый вход. Действующая установка сервера и роутер не изменены публикацией этого релиза.

После запуска проверьте с другой сети `https://ВАШ_ПУБЛИЧНЫЙ_IP:8765/api/health`: без предупреждения TLS должен появиться JSON с `ok: true`. Для IP Let's Encrypt выдаёт сертификат на 160 часов; автоматическое продление требует работающего Caddy, открытого TCP 80 и доступа к центру сертификации. Если публичный IP изменится, попросите пользователей не вводить данные в старой копии, обновите настройки шлюза и раздайте новую копию. Статический IP или домен надёжнее. Закрытый ключ, папку `data` и серверный архив пользователям не передавать. Публичный сервис не проходил независимый аудит.

## Проверки и ограничения

Проверяются сборка Windows, лоадер и обновление, сервер и SQLite, шлюз Caddy с локальным тестовым TLS-сертификатом, отказ недоверенного сертификата в клиенте, доступ только к разрешённым API и запрет подмены IP для лимита входа. Реальную выдачу сертификата на IP владельца, его маршрутизатор, брандмауэр, смену IP, работу через чужой интернет и реальную GTA5 тесты не подтверждают. При недоступности порта 80, центра сертификатов или самого сервера соединение не заработает; проверку TLS отключать нельзя.
