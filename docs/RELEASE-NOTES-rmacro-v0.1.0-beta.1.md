# RMacro 0.1.0-beta.1 — лоадер и личный сервер

Предварительная версия состоит из **двух разных архивов**:

- **RMacro-v0.1.0-beta.1-Windows.zip** — лоадер для пользователей: вход, сохранённая сессия, UID, остаток и дата подписки, предупреждение за 3 дня, профиль и встроенный RMFish. `RMacro.exe` не устанавливает и не создаёт отдельный скрипт; окно продукта и кнопки остановки остаются видимыми.
- **RMacro-Server-v0.1.0-beta.1-Windows.zip** — для владельца сервера: SQLite-база, веб-панель, BAT-файлы создания администратора, запуска, сброса админ-пароля и резервного копирования. Требуется Python 3.9+ на Windows. В архиве **нет** готового администратора, пользователей, базы или ключей.

## Начало работы

1. Распакуйте серверный ZIP на своём ПК, установите Python 3 и запустите `SETUP-ADMIN.bat`; придумайте собственные логин и пароль администратора. Затем запустите `START-SERVER.bat` и оставьте окно открытым.
2. На этом же ПК откройте `http://127.0.0.1:8765/admin/`, войдите как администратор, создайте пользователя и добавьте ему время для RMFish.
3. Распакуйте клиентский ZIP и запустите `RMacro.exe`. Введите сервер `http://127.0.0.1:8765` для входа на том же ПК и данные созданного пользователя. Для других компьютеров сначала настройте HTTPS и реальный адрес сервера по `README-SERVER.md` внутри серверного архива.

В панели доступны выдача времени по продуктам, сброс HWID, блокировка/разблокировка, смена пароля, отзыв подписки и журнал действий. Вход привязывается к псевдонимному идентификатору Windows; сброс завершает текущие сессии. Токен клиента защищается DPAPI Windows, пароль клиента не сохраняется. Сессия действует до 30 дней, затем нужен новый вход.

## Важно о безопасности и ограничениях

- Сервер по умолчанию доступен **только на том же ПК**. Для удалённого управления и пользователей настройте домен, действительный HTTPS-сертификат, доступность сети и защиту `/admin/`. Удалённый HTTP запрещён лоадером и сервером; встроенный сервер — начальная версия без независимого аудита, не готовый крупный публичный SaaS. Защитите базу, резервные копии, серверный ПК и TLS-ключ.
- Подписка проверяется при открытии продукта и регулярно во время работы. При отзыве доступа или потере связи на приблизительно 90 секунд запрашивается остановка и блокируется повторный запуск. Зависший системный вызов нельзя прервать таким запросом.
- Код RMFish встроен в лоадер, но это **не DRM**: программу, работающую на чужом ПК, можно модифицировать, а автономная версия и исходники уже опубликованы. Другим продуктам потребуется собственная реализация в лоадере.
- До рыбалки проверьте F10 в активной игре и запись «F10 получен» в диагностике RMFish. Для принудительной остановки приложены BAT и инструкция; они завершают `RMacro.exe`, не GTA5. Реальные GTA5/RMRP и физические горячие клавиши не проверены. Проверьте правила игрового сервера.
