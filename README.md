# autofish-jta / RMFish

**RMFish** — Windows-программа с меню для автоматизации рыбалки в RMRP (GTA5). Она наблюдает за экраном, нажимает ЛКМ для заброса и вываживания и ждёт следующую шкалу. Память игры не читается и не изменяется.

RMFish 1.28.0-beta.1 и встроенный в Eternal Core 1.1.0 RMFish содержат изменения для повторного заброса и экспериментальный автоотход с обучением. В Eternal Core 1.1.0 также добавлены проверка компонентов и обновление лоадера. Старые RMFish 1.27.0-beta.6 и Eternal Core 1.0.0 этих изменений не содержат.

> Это визуальная автоматизация по предоставленным скриншотам, а не официальный инструмент RMRP. Работа зависит от версии интерфейса игры, разрешения и того, принимает ли игра синтетические клики. Проверьте правила сервера: использование автоматизации может быть запрещено.
>
> **RMFish 1.28.0-beta.1 — предварительная версия:** работа в GTA5/RMRP, реальное уведомление об окончании рыбы и аварийные клавиши при перехвате ввода игрой ещё не проверены. До рыбалки обязательно проверьте F10, пока игра активна и бот остановлен; если клавиша не срабатывает — не запускайте бота. AI-распознавания из 1.26.0 нет.

## Eternal Core 1.3.0

**Eternal Core** — лоадер игр и макросов с отдельным сервером и сайтом администратора. Администратор входит на сайт и в лоадер с одним логином и паролем; в профиле можно сменить пароль, активировать ключ подписки и открыть техподдержку. Администратор создаёт ключ для продукта и срока, задаёт дату окончания возможности активации, лимит разных пользователей, общее число активаций и лимит на человека. Библиотека показывает игры и выданные пользователю макросы, включая истёкшие. Запускается только встроенный RMFish; добавление другого макроса в каталог не добавляет его исполнение. Самостоятельный RMFish остаётся доступен.

Сервер работает у владельца на Windows (Python 3.9+, SQLite без дополнительных пакетов). В панели можно управлять пользователями, играми, макросами, подписками, ключами и HWID. Сначала запустите `rmacro/server/SETUP-ADMIN.bat`, затем `START-SERVER.bat`. По выбранной настройке сервер и лоадер используют LAN-адрес `192.168.0.105:8765`; панель — `http://192.168.0.105:8765/admin/`. Адрес должен принадлежать серверному ПК. **HTTP в LAN не шифрует пароли, токены и ключи: не открывайте его в интернет.** Для публичного доступа нужен HTTPS. Адрес в интерфейсе лоадера не показывается, но его можно извлечь из файла или сетевого соединения. Установка, миграция старой базы и настройка HTTPS: [инструкция сервера](rmacro/server/README-SERVER.md). Клиент выпускается отдельно на [странице Eternal Core 1.3.0](https://github.com/marlen71/AutoFish/releases/tag/eternal-core-v1.3.0); серверная программа и база не обновляются автоматически. Для исправления сохранения входа на сайте нужно вручную заменить один файл интерфейса, как описано ниже.

Подписка проверяется сервером; при отзыве или длительной потере связи RMFish получает запрос остановки. Это не защищённая от модификации DRM: код и старые автономные версии уже опубликованы. GTA5 и физические горячие клавиши не проверялись — перед использованием обязательно проверяйте F10. Подробности: [инструкция клиента](rmacro/client/INSTRUCTIONS.txt).

### Компоненты и обновление Eternal Core 1.1.0

Распакуйте клиентский архив целиком в папку с правом записи и запустите `SETUP-ETERNAL-CORE.bat`: он проверит .NET Framework 4.5+. При отсутствии предложит загрузить установщик .NET 4.8 с Microsoft, проверит его цифровую подпись и попросит подтверждение UAC; возможна перезагрузка. На Windows 10/11 нужный .NET обычно уже есть. Встроенному RMFish не нужны Python, pip, OCR или отдельный серверный компонент; установка их не меняет. Автоматическая установка Microsoft и UAC на реальной машине не проверялись. Предыдущий Eternal Core 1.0.0 такой проверки и автообновления не имеет: переход на новую сборку выполняется вручную один раз. Закройте старый лоадер, сохраните его резервную копию и распакуйте новый клиент. Если администратор раньше менял встроенный адрес подключения, ему нужно заново выполнить серверный `CONFIGURE-LOADER.bat` именно для нового EXE и положить результат под именем `EternalCore.exe`; иначе используется адрес по умолчанию. Сервер и его базу заменять не нужно.

Новая версия автоматически проверяет стабильные `eternal-core-vX.Y.Z` релизы **только в `marlen71/AutoFish`**; кнопка «Обновления» позволяет проверить вручную. После согласия пользователя скачивается только `EternalCore.exe`, размер и SHA-256 сверяются с GitHub API. Сам RMFish встроен в этот EXE и меняется вместе с ним; сервер, его база, Python и остальные файлы обновляться не будут. Адрес подключения и закреплённый публичный корень сертификата из настроенного EXE сохраняются без показа в интерфейсе, сессия и настройки не удаляются. Для замены нужна доступная для записи папка на файловой системе с поддержкой `File.Replace`. Программа не обновляется, пока открыто окно RMFish. После перезапуска проверяется открытие нового окна, при неудаче выполняется откат; резервный `previous.exe` остаётся в `.eternal-core-update-…`. Проверка SHA-256 защищает от повреждения при доставке, но не заменяет подпись приложения и не защищает при компрометации владельца репозитория. Ошибка сети не блокирует вход в установленную версию.

### Доступ клиентов из другого интернета

Адрес LAN не доступен из другой сети. Для интернет-клиентов вручную установите серверный патч `EternalCore-Internet-Update-v1.3.0.zip`, настройте HTTPS-шлюз и создайте новую копию лоадера, как описано в [инструкции сервера](rmacro/server/README-SERVER.md). Caddy автоматически создаёт внутренний сертификат, которому доверяет только настроенный EXE; порт 80 и Let's Encrypt не нужны. Внешний TCP 8765 должен быть доступен; админ-панель остаётся на серверном ПК. Старым пользователям один раз раздаётся новый EXE. Резервируйте `data/internet-gateway` отдельно от базы и не раздавайте закрытые ключи. При смене IP или корня понадобится новая копия; порт старого LAN HTTP в интернет открывать нельзя.

### Сохранение входа на сайте

Исправление сайта устанавливается **отдельно и вручную**, не через автообновление лоадера: скачайте `EternalCore-Admin-Update-v1.1.0.zip` со страницы релиза, остановите сервер, сохраните копию `static/app.js`, затем замените только этот файл файлом `static/app.js` из архива исправления. Папку `data` с базой и остальные серверные файлы не заменяйте. Запустите сервер и войдите в панель один раз; после этого F5 в той же вкладке сохраняет вход, пока серверная сессия действительна (не более 12 часов). При нажатии «Выйти», отзыве сессии или смене пароля потребуется новый вход. Пароль браузерный код не сохраняет; токен хранится в `sessionStorage` вкладки и доступен скриптам того же сайта, поэтому выходите на общих компьютерах. При временной потере связи токен не удаляется и повторная загрузка может восстановить вход. HTTP в LAN по-прежнему не шифрует данные.

## Быстрый запуск

1. Закройте прежний RMFish. Скачайте `RMFish-v1.28.0-beta.1-Windows.zip` на [странице предварительного релиза](https://github.com/marlen71/AutoFish/releases/tag/v1.28.0-beta.1) и распакуйте в отдельную доступную для записи папку. Не запускайте программу непосредственно из архива.
2. Запустите GTA5 / RMRP в оконном режиме без рамки, формат **16:9**, желательно **1920×1080**. Всё окно игры должно быть видно на экране.
3. Запустите **`RMFish.exe`** или **`RMFish.bat`**, но не нажимайте «Включить». Переключитесь в игру, удерживайте **F10 около секунды**, затем проверьте журнал в «Диагностике»: должна появиться запись «F10 получен». Если записи нет, не запускайте бота.
4. В зоне рыбалки **вручную** нажмите `I` → выберите бамбуковую удочку → **«Ловить рыбу»** → **«Хлебный мякиш»**.
5. Нажмите **«Включить»** и вернитесь в игру. По умолчанию рыбалка автоматически остановится через **120 секунд**, даже во время паузы; предел меняется в настройках от 1 до 1800 секунд.
6. Для остановки используйте **F10**, либо удерживайте **Esc 2 секунды** или **обе кнопки мыши 2 секунды**. Возможна блокировка всех этих способов игрой — см. аварийные действия ниже.

Для EXE нужны Windows 10/11 и .NET Framework 4.5 или новее (обычно уже входит в Windows). Python, PowerShell, файлы исходного кода и сторонние библиотеки не нужны. `RMFish.exe` можно скачать и отдельно; иконка и логотип встроены. Бинарный файл не подписан цифровым сертификатом, поэтому Windows может предупредить о неизвестном издателе.

В архиве `RMFish.bat` запускает соседний EXE. Запуск из исходников через тот же BAT тоже сохранён: если EXE рядом нет, нужны полная папка репозитория и Windows PowerShell 5.1. В режиме исходников BAT применяет `-ExecutionPolicy Bypass` только к своему процессу и не изменяет системную политику.

### Новое меню

У окна собственная тёмная рамка: перетаскивайте его за верхнюю полосу; кнопки справа сворачивают и закрывают программу. `Alt+F4` тоже закрывает окно и запрашивает остановку. Круглая кнопка в центре включает и останавливает рыбалку; отдельная кнопка «Стоп» доступна на любой вкладке. Боковое меню открывает настройки, инструкцию и диагностику. Ползунок на главной странице меняет **интервал ЛКМ при вываживании** (35–250 мс): справа быстрее, слева медленнее. Он связан с настройками и применяется при следующем запуске; скорость распознавания при забросе им не меняется. Удочка и наживка на панели — подсказка для ручного выбора, не сведения о фактическом инвентаре. Поля настроек можно редактировать с клавиатуры или кнопками «−» / «+»; журнал прокручивается колесом и позволяет копировать текст.

### Почему подготовка вручную?

В исходных материалах указано, что игра может игнорировать программные нажатия клавиш, в том числе `I`. Кроме того, предметы и контекстное меню могут менять положение. По умолчанию подготовка выполняется вручную. Только при включённом и обученном автоотходе программа открывает инвентарь и воспроизводит три записанных пользователем действия, предварительно сравнивая каждый элемент с образцом; при несовпадении она прекращает работу. Это не гарантирует правильный выбор в любой ситуации. Если игра после вываживания сама показывает следующую шкалу заброса, RMFish продолжит цикл; если нет — подготовьте следующий заброс вручную. Наличие и количество наживки программа не проверяет; тайм-аут не означает, что она закончилась.

### Автоотход при исчерпании рыбы — экспериментально

В текущей сборке откройте **Настройки → «Автоотход…»**. Функция изначально выключена. Не включайте её без проверки F10 в игре, свободного прямого пути и постоянного наблюдения: S и W по 7 секунд **не гарантируют возврат в точную исходную точку**, а игра может игнорировать ввод. Сама игра и реальное уведомление об исчерпании рыбы пока не проверены.

1. Остановите бота. Выберите «Записать уведомление», переключитесь в GTA5 и нажмите **F9**, когда видно именно сообщение об окончании рыбы над миникартой. В открывшемся снимке обведите всю неизменную надпись без значка и пустых полей. **Не обучайте на «Забросьте удочку» или другом уведомлении:** программа сопоставляет картинку, а не понимает смысл текста. Изображение хранится только в памяти, на диск записывается маска выбранного текста.
2. Выберите, какой кнопкой мыши открывается удочка, и нажмите «Записать удочку и наживку». В игре вручную откройте `I/Ш`, наведите на удочку и нажмите **F9**, дождитесь сигнала и нажмите её выбранной кнопкой. Так же наведите на «Ловить рыбу», нажмите F9, затем ЛКМ; наведите на «Хлебный мякиш», нажмите F9, затем ЛКМ. Подводите курсор к характерному значку или тексту. F10 отменяет запись. Изменение кнопки удочки требует повторной записи.
3. Включите автоотход в этом же окне и сохраните. Все образцы должны быть записаны при одинаковом разрешении клиентской области; при изменении разрешения или интерфейса запишите их заново. Без обоих образцов запуск с включённым автоотходом блокируется.
4. При совпадении текста в нескольких кадрах программа один раз коротко нажмёт пробел, удержит S 7 секунд, затем W 7 секунд, откроет `I/Ш` и проверит каждый записанный элемент перед кликом. После выбора наживки она снова ждёт шкалу. Повтор по тому же не исчезнувшему уведомлению блокируется; новое срабатывание возможно только после его отсутствия не менее 2 секунд и не ранее чем через 60 секунд после предыдущего. На потерю фокуса, F10, STOP, истечение лимита сессии или несовпадение экрана маршрут прерывается без автоматического повтора; проверьте позицию и подготовьте снасти вручную.

Короткие образцы элементов инвентаря и маска уведомления сохраняются локально в `%LOCALAPPDATA%\RMFish\fish-gear.dat` и `fish-notice.dat`. Они могут содержать фрагменты интерфейса и не передаются на сервер. Настройка и детектор основаны на пользовательских образцах: возможны ложные совпадения и пропуски, особенно после изменения HUD, и они не подтверждают наличие рыбы или точное положение персонажа.

## Управление

| Действие | Как выполнить |
| --- | --- |
| Запустить / остановить | кнопки в меню или **F8** |
| Аварийно остановить | **F10**; либо удерживайте **Esc 2 с** или **ЛКМ + ПКМ 2 с** |
| Остановить с рабочего стола | `STOP.bat` — мягко; `EMERGENCY-STOP.bat` — принудительное завершение `RMFish.exe` |
| Проверить распознавание без кликов | сначала остановить бота, переключиться в GTA5 и нажать **F9**; результат будет в меню «Диагностика» |
| Проверить из меню | «Диагностика» → «Проверить через 3 сек» → переключиться в игру |

F9 и F10 дополнительно проверяются отдельным потоком, но игра, Windows или другое ПО могут блокировать и регистрацию горячих клавиш, и считывание их состояния. Не рассчитывайте на клавиши без проверки в игре. На некоторых клавиатурах нужен **Fn+F10**.

`STOP.bat` создаёт `STOP.txt` рядом с программой для мягкой остановки: если текущий системный вызов завис, сигнал обработается только после его возврата. `EMERGENCY-STOP.bat` сначала отправляет этот сигнал, затем принудительно завершает процессы `RMFish.exe`; GTA5 он не закрывает. В режиме исходного PowerShell-скрипта BAT отправляет сигнал, но не завершает процессы PowerShell. Если RMFish запущен от администратора, аварийный BAT тоже может потребовать прав администратора. После принудительного закрытия, если ЛКМ кажется зажатой, нажмите и отпустите её один раз.

**Если игру нельзя свернуть и кнопки остановки не сработали:** `Ctrl+Alt+Delete` → «Диспетчер задач» → вкладка «Подробности» → `RMFish.exe` → «Завершить задачу». Не завершайте `GTA5.exe`. В режиме запуска из исходников найдите именно `powershell.exe` с путём к `RMFish.ps1` в столбце «Командная строка»; не закрывайте все процессы PowerShell. Если диспетчер совсем недоступен, выход из учётной записи закроет программы и может привести к потере несохранённых данных.

Клики разрешены **только пока окно процесса `GTA5.exe` активно и не изменилось после снимка**. При обычной рыбалке Alt+Tab или неподходящий размер окна вызывает паузу. Во время автоотхода потеря фокуса прекращает всю сессию: продолжать маршрут с неизвестной позиции нельзя. При обычной остановке программа пытается отпустить свои кнопки мыши и клавиатуры; зависший системный вызов или принудительное завершение могут этому помешать. После принудительного завершения при необходимости нажмите и отпустите `S`, `W`, пробел, `I` и кнопку мыши. Статус «Остановка…» означает, что запрос отправлен, но текущая операция ещё не завершилась. Одновременно запускается только один экземпляр программы.

## Принцип работы и ограничения

- Горизонтальная шкала ищется на нескольких высотах; отдельно определяются широкая зелёная полоса, узкий **светло-зелёный участок** и белый крючок. Нажатие происходит, когда распознанный крючок находится внутри светлого участка с небольшим отступом. Если участок на момент кадра не найден, ранее подтверждённый в двух кадрах участок той же полосы может использоваться ещё до 200 мс; крючок при этом должен быть виден. Без подтверждённой цели или крючка нажатия нет; переход к произвольному нажатию по таймеру отключён. Если шкала не исчезла за 18 секунд, работа останавливается.
- По ярким зелёному и красному участкам определяется вертикальная шкала вываживания. Пока она видна, RMFish выполняет короткие нажатия ЛКМ. На первом кадре без шкалы клики прекращаются; окончание фазы подтверждается несколькими кадрами. Предельное время вываживания — 45 секунд.
- Координаты заданы для **1920×1080** и масштабируются по размеру клиентской области игры; поддерживаются окна 16:9 не меньше 1280×720. Другой масштаб интерфейса, обрезанное/перекрытое окно, цветокоррекция, изменение HUD или эксклюзивный полноэкранный режим могут помешать распознаванию. 1280×720 проверен на уменьшенных копиях скриншотов, а не в самой игре.
- По умолчанию период проверки экрана составляет 20 мс, минимальный интервал ЛКМ при вываживании — 35 мс. В фазе заброса целевой период ограничен 15 мс, включая снимок и анализ; фактическая частота зависит от компьютера. Если крючок перескочил светлый участок между кадрами, программа не угадывает момент нажатия. Отдельное ожидание шкалы ограничено 300 секундами; `0` отключает только этот лимит.
- Для безопасности вся сессия ограничена **120 секундами по умолчанию** (настраивается от 1 до 1800 секунд, без полного отключения). Этот лимит идёт и на паузе и отправляет запрос остановки. При зависании Windows или процесса он не гарантирован.
- Счётчик забросов увеличивается, когда шкала исчезла после отправленного клика; подавленный из-за удержания пользователем ЛКМ клик не считается. Счётчик «вываживаний» увеличивается при исчезновении вертикальной шкалы или подтверждённом появлении следующего заброса. Это **не подтверждение, что игра приняла ввод, заброс успешен или рыба поймана**. Ошибки в игре и пустая наживка не распознаются.

## Если не работает

- **«GTA5 не найден» / пауза:** откройте именно окно процесса `GTA5.exe`, переключитесь в него, проверьте формат и размер окна. RMFish намеренно не перехватывает фокус обратно.
- **F9 не видит шкалу, крючок или светлый участок:** остановите рыбалку, затем нажмите F9, пока шкала отображается и GTA5 находится в фокусе. В «Диагностике» показаны координаты широкой зелёной зоны, светлого участка и крючка. Попробуйте 1920×1080, стандартный масштаб HUD и оконный режим без рамки, отключите перекрывающие оверлеи.
- **Шкала определяется, но игра не реагирует на клики:** игра может блокировать синтетический ввод или работать с более высоким уровнем прав. Запускайте RMFish с теми же правами, что и игру; если игра запущена от администратора, можно запустить `RMFish.exe` от администратора. Успех не гарантируется.
- **EXE не запускается:** убедитесь, что это Windows 10/11 и установлен .NET Framework 4.5 или новее. Для запуска из исходников через BAT дополнительно нужен Windows PowerShell 5.1 и полная структура папок репозитория.
- **STOP.bat не может создать файл:** переместите всю папку в место, где есть право записи. Если F10 не работает, завершите `RMFish.exe` через диспетчер задач.

Настройки сохраняются в `%LOCALAPPDATA%\RMFish\settings.ini`; журнал событий находится в окне программы и не содержит скриншотов. Существующие файлы `eternal_fishmod.py`, архивы и изображения в корне — материалы прежнего проекта; для запуска RMFish они не нужны.

## Сборка и проверка для разработчиков

В Windows из корня репозитория соберите самостоятельный EXE встроенным компилятором .NET Framework:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-RMFish.ps1
```

Результат — `dist\RMFish.exe`. Запуск тестов:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
```

Тесты проверяют детекторы на обрезанных кадрах из предоставленных скриншотов и на синтетических данных, движение белого крючка по реконструированной шкале, переходы состояний, ограничение времени, остановку и работу без фокуса через тестовый интерфейс ввода. Движение крючка сымитировано на основе неподвижного изображения, а не записано в игре. При имитации зависшего снимка проверяется, что F10 не зависит от диагностики и устаревший тестовый клик не выполняется после возврата из снимка. В Windows CI проверяются окно и его кнопки, перетаскивание синтетической мышью, настройки и журнал, кнопки старта/остановки, встроенные изображения, синтетические F9/F10 при заблокированном потоке меню и аварийный BAT; реальные клавиатура и GTA5 не проверяются. Файлы в `tests/fixtures` — сжатые BGRA-области экрана, а не фотографии всего рабочего стола.
