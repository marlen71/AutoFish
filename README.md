# AutoFish / Assist

Независимые программы в одном репозитории. Рыбалка не подключается к Assist.

## Assist — AI Workspace / Rebuild 2

Экранный AI для Windows: захват DXGI/MSS, PyTorch/ONNX, диагностика без ввода,
единое меню, ESP, контролируемое наведение и локальное обучение.

- [Скачать Assist.zip](https://github.com/marlen71/AutoFish/raw/refs/heads/arena/6d9323ef-autofish/Assist.zip)
- Распаковать **весь** архив → `Start_Assist.bat` (Python 3.11/3.12 x64).
- Сначала **Обзор → Проверить захват и модель**, затем запуск оверлея и F8 в целевом окне.
- Экспорт ONNX доступен в меню. Необязательные ускорители: `Install_Acceleration.bat`.
- Локальная сборка Windows EXE: `Build_Assist_EXE.bat` после установки зависимостей.
- [Полная инструкция](screen_assist/README.md).

Веса пользователя `game_detector_final.pt` включены в архив. Реальное ускорение,
качество распознавания и совместимость с целевым приложением требуют проверки;
наличие GPU/provider не гарантирует прирост скорости. Для разрешённого тестирования,
без обещаний необнаружимости и без обхода античита.
