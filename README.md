# autofish-jta / RMFish

**RMFish** — Windows-программа с меню для автоматизации рыбалки в RMRP (GTA5). Она наблюдает за экраном, нажимает ЛКМ для заброса и вываживания и ждёт следующую шкалу. Память игры не читается и не изменяется.

> Это визуальная автоматизация по предоставленным скриншотам, а не официальный инструмент RMRP. Работа зависит от версии интерфейса игры, разрешения и того, принимает ли игра синтетические клики. Проверьте правила сервера: использование автоматизации может быть запрещено.
>
> **Версия 1.27.0-beta.1 — предварительная:** запуск на Windows и работа в GTA5/RMRP ещё не проверены. Это новая визуальная реализация, а не продолжение всех возможностей версии 1.26.0: автоматического управления инвентарём и AI-распознавания в ней нет. Стабильный релиз 1.26.0 остаётся доступен отдельно.

## Быстрый запуск

1. Скачайте архив `RMFish-v1.27.0-beta.1-Windows.zip` на [странице предварительного релиза](https://github.com/marlen71/AutoFish/releases/tag/v1.27.0-beta.1) и распакуйте его в доступную для записи папку, например на рабочем столе. Не запускайте программу непосредственно из архива.
2. Запустите GTA5 / RMRP, установите формат **16:9**, желательно **1920×1080**, и оконный режим без рамки. Всё окно игры должно быть видно на экране.
3. Встаньте в зоне рыбалки. **Вручную** нажмите `I` → выберите бамбуковую удочку → **«Ловить рыбу»** → **«Хлебный мякиш»**. Начать работу RMFish можно как до, так и после появления шкалы заброса или вываживания.
4. Дважды щёлкните **`RMFish.exe`**, нажмите **«Старт»** и вернитесь в игру. По умолчанию окно RMFish сворачивается.
5. Остановите через **F8**, **F10**, кнопку **«Стоп»** или файл **`STOP.bat`** из архива.

Для EXE нужны Windows 10/11 и .NET Framework 4.5 или новее (обычно уже входит в Windows). Python, PowerShell, файлы исходного кода и сторонние библиотеки не нужны. `RMFish.exe` можно скачать и отдельно; иконка встроена. Бинарный файл не подписан цифровым сертификатом, поэтому Windows может предупредить о неизвестном издателе.

Запуск из исходников через `RMFish.bat` тоже сохранён: для него нужны полная папка репозитория и Windows PowerShell 5.1. BAT применяет `-ExecutionPolicy Bypass` только к своему процессу и не изменяет системную политику.

### Почему подготовка вручную?

В исходных материалах указано, что игра может игнорировать программные нажатия клавиш, в том числе `I`. Кроме того, предметы и контекстное меню могут менять положение. Поэтому RMFish **не открывает инвентарь и не выбирает предметы вслепую**. Если игра после вываживания сама показывает следующую шкалу заброса, RMFish продолжит цикл; если нет — подготовьте следующий заброс вручную. Наличие и количество наживки программа пока не проверяет.

## Управление

| Действие | Как выполнить |
| --- | --- |
| Запустить / остановить | кнопки в меню или **F8** |
| Аварийно остановить | **F10** или двойной щелчок по `STOP.bat` |
| Проверить распознавание без кликов | переключиться в GTA5 и нажать **F9**; результат будет в меню «Диагностика» |
| Проверить из меню | «Диагностика» → «Проверить через 3 сек» → переключиться в игру |

Горячие клавиши работают и при свёрнутом окне, если их не заняло другое приложение; сообщение об этом появится в журнале. `STOP.bat` создаёт `STOP.txt` рядом с программой. Для нового запуска нажмите «Старт» или F8 — старый файл остановки удалится. Не перемещайте `STOP.bat` отдельно от остальной папки.

Клики разрешены **только пока окно процесса `GTA5.exe` активно и не изменилось после снимка**. При Alt+Tab, сворачивании или неподходящем размере окна программа переходит в паузу; вернитесь в игру, чтобы продолжить. Удерживаемая программой ЛКМ отпускается даже при остановке. При закрытии окна RMFish работа прекращается. Одновременно запускается только один экземпляр программы.

## Принцип работы и ограничения

- По горизонтальной шкале определяется зелёная зона между красными краями и белый крючок. Первые 10 секунд программа целится в центральную часть зоны, затем — в любую безопасную часть. Если шкала не исчезла за 18 секунд, работа останавливается.
- По ярким зелёному и красному участкам определяется вертикальная шкала вываживания. Пока она видна, RMFish выполняет короткие нажатия ЛКМ. На первом кадре без шкалы клики прекращаются; окончание фазы подтверждается несколькими кадрами. Предельное время вываживания — 45 секунд.
- Координаты заданы для **1920×1080** и масштабируются по размеру клиентской области игры; поддерживаются окна 16:9 не меньше 1280×720. Другой масштаб интерфейса, обрезанное/перекрытое окно, цветокоррекция, изменение HUD или эксклюзивный полноэкранный режим могут помешать распознаванию. 1280×720 проверен на уменьшенных копиях скриншотов, а не в самой игре.
- По умолчанию экран проверяется каждые 20 мс, минимальный интервал ЛКМ — 35 мс. Реальная частота зависит от времени снимка и настроек компьютера. Ожидание шкалы ограничено 300 секундами; `0` в настройках означает ожидание без ограничения. Таймер ожидания не идёт, пока игра не в фокусе.
- Счётчик забросов увеличивается, когда шкала исчезла после клика; счётчик «вываживаний» — когда исчезла вертикальная шкала. Это **не подтверждение успешного заброса или поимки**. Ошибки в игре и пустая наживка не распознаются.

## Если не работает

- **«GTA5 не найден» / пауза:** откройте именно окно процесса `GTA5.exe`, переключитесь в него, проверьте формат и размер окна. RMFish намеренно не перехватывает фокус обратно.
- **F9 не видит шкалу:** нажмите F9, пока шкала отображается и GTA5 находится в фокусе. Посмотрите результат и журнал в «Диагностике». Попробуйте 1920×1080, стандартный масштаб HUD и оконный режим без рамки, отключите перекрывающие оверлеи.
- **Шкала определяется, но игра не реагирует на клики:** игра может блокировать синтетический ввод или работать с более высоким уровнем прав. Запускайте RMFish с теми же правами, что и игру; если игра запущена от администратора, можно запустить `RMFish.exe` от администратора. Успех не гарантируется.
- **EXE не запускается:** убедитесь, что это Windows 10/11 и установлен .NET Framework 4.5 или новее. Для запуска из исходников через BAT дополнительно нужен Windows PowerShell 5.1 и полная структура папок репозитория.
- **STOP.bat не может создать файл:** переместите всю папку в место, где есть право записи, или остановите через F10.

Настройки сохраняются в `%LOCALAPPDATA%\RMFish\settings.ini`; журнал событий находится в окне программы и не содержит скриншотов. Существующие файлы `eternal_fishmod.py`, архивы и изображения в корне — материалы прежнего проекта; для запуска RMFish они не нужны.

## Сборка и проверка для разработчиков

В Windows из корня репозитория соберите самостоятельный EXE встроенным компилятором .NET Framework:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-RMFish.ps1
```

Результат — `dist\RMFish.exe`. Запуск тестов:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
```

Тесты проверяют детекторы на обрезанных кадрах из предоставленных скриншотов и на синтетических данных, переходы состояний, ограничения времени, остановку и работу без фокуса через тестовый интерфейс ввода. Реальная игра и управление мышью для этих тестов не нужны. Файлы в `tests/fixtures` — сжатые BGRA-области экрана, а не фотографии всего рабочего стола.
