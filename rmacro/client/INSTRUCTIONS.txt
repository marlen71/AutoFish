RMacro 0.1.0-beta.1 — лоадер RMFish

1. Распакуйте ZIP в доступную для записи папку. Запустите RMacro.exe.
2. Укажите адрес сервера, полученный от администратора. Для сервера на этом же ПК: http://127.0.0.1:8765. Для удалённого сервера необходим https://адрес с действительным сертификатом. Адрес 127.0.0.1 на другом компьютере не является адресом вашего сервера.
3. Введите логин и пароль пользователя (не администратора). Если включено «Запомнить вход», случайный токен сохраняется в защищённом хранилище текущего пользователя Windows; пароль не сохраняется. При первом входе аккаунт привязывается к идентификатору Windows.
4. На экране продукта видны ваш UID, остаток времени и дата окончания подписки. Если до окончания активной подписки осталось не более трёх суток, при входе отображается предупреждение. Раздел «Профиль» показывает все продукты.
5. Нажмите «Открыть RMFish». Продукт встроен в RMacro.exe и открывается без установки отдельного скрипта. Окно RMFish видимо: в нём находятся настройки, диагностика, запуск и остановка. Программа не внедряется в GTA5 и не читает память игры.

ОБЯЗАТЕЛЬНО ПЕРЕД РЫБАЛКОЙ: откройте GTA5 в оконном режиме без рамки 16:9, не запускайте рыбалку, удерживайте F10 примерно секунду, вернитесь в RMFish → «Диагностика» и убедитесь, что есть запись «F10 получен». Если её нет — не запускайте бота. Горячие клавиши могут блокироваться игрой; сначала проверьте в реальной игре.

Для остановки: F10; запасные варианты — удержание Esc или обеих кнопок мыши две секунды. Кнопка «Стоп» есть во вкладках RMFish. STOP-RMACRO.bat отправляет мягкий сигнал; EMERGENCY-RMACRO.bat сначала сигнализирует, затем принудительно завершает RMacro.exe, не GTA5.exe. Если RMacro запущен от администратора, аварийному BAT тоже могут потребоваться права администратора. Если игру нельзя свернуть: Ctrl+Alt+Delete → Диспетчер задач → Подробности → завершить RMacro.exe, не GTA5.exe. После принудительного завершения при необходимости нажмите и отпустите левую кнопку мыши.

При отзыве подписки/блокировке серверная проверка запрашивает остановку, а при потере связи — примерно через 90 секунд без подтверждения. Рабочий системный вызов нельзя принудительно прервать мягкой остановкой. Не оставляйте бота без присмотра: обязательный лимит сессии по умолчанию — 120 секунд.

Подготовка рыбалки выполняется вручную: I/Ш → бамбуковая удочка → «Ловить рыбу» → «Хлебный мякиш». RMFish ищет белый крючок и узкую светло-зелёную часть шкалы и не нажимает при их отсутствии. Реальные GTA5, физическая клавиатура и поведение при блокировке ввода игрой не проверены. Проверьте правила игрового сервера. Старые самостоятельные версии RMFish и исходный код остаются доступными; это не защищённая от модификации DRM.

Сессия: %LOCALAPPDATA%\RMacro\session.dat; настройки RMFish: %LOCALAPPDATA%\RMFish\settings.ini. «Выйти из аккаунта» удаляет сохранённую сессию с этого ПК. Для смены устройства или после переустановки Windows обратитесь к администратору для сброса HWID. Нужны Windows 10/11, .NET Framework 4.5 или новее и запущенный доступный сервер. Сервер необходимо настроить отдельно; данный архив его не содержит.
