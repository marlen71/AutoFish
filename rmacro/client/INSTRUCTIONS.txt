Eternal Core — release v1
Лоадер игр, макросов и подписок для Windows

1. Распакуйте клиентский архив целиком в доступную для записи папку и запустите EternalCore.exe. Подключение уже настроено владельцем; поля адреса в лоадере нет. При проблемах используйте «Тех. Поддержка» на экране входа или в профиле: https://discord.gg/jVKudmmBbA.
2. Введите логин и пароль. Администратор входит в лоадер с теми же данными, что и на сайте; отдельный аккаунт для него создавать не нужно. Сам вход не выдаёт подписку автоматически. При первом входе аккаунт привязывается к устройству Windows. Если выбрано «Запомнить вход», Windows DPAPI сохраняет токен текущего пользователя Windows, но не пароль.
3. В «Профиле» можно активировать ключ: вставьте его и нажмите «Активировать». Ключ добавляет указанный администратором срок к действующей подписке или начинает её с текущего времени, если она истекла. Каждый новый ввод может расходовать очередную активацию и добавлять время; число людей, общее число активаций, лимит на человека и дата окончания возможности активации задаются администратором. Если ответ потерян, повторите тот же ключ в текущем окне — повторная отправка этой попытки не спишет время дважды. После перезапуска перед повтором сначала проверьте подписку.
4. Для смены пароля в профиле введите старый пароль, новый и подтверждение. Минимум 8 символов, для администратора — 12. Текущая сессия лоадера сохраняется; остальные сессии завершаются. Для администратора новый пароль одновременно действует на сайте, его сессии на сайте завершаются.
5. В «Библиотеке» выберите игру и выданный вам макрос. Истёкшие подписки остаются видимыми. Карточка показывает UID, оставшееся время и дату окончания; срок менее трёх суток отмечается предупреждением. Списки прокручиваются колесом и выбираются стрелками клавиатуры.
6. Выберите RMFish и нажмите «Открыть». Он встроен в EternalCore.exe и открывается без отдельного скрипта. Другие выданные макросы видны в библиотеке, но для запуска нужна версия лоадера с их реализацией. Окно RMFish содержит настройки, диагностику, запуск и остановку; программа не внедряется в GTA5 и не читает память игры.

ОБЯЗАТЕЛЬНО ПЕРЕД РЫБАЛКОЙ: откройте GTA5 в оконном режиме без рамки 16:9, не запускайте рыбалку, удерживайте F10 примерно секунду, вернитесь в RMFish → «Диагностика» и убедитесь, что есть запись «F10 получен». Если её нет — не запускайте бота. Игра может блокировать горячие клавиши; сначала проверьте их в реальной игре.

Для остановки: F10; запасные варианты — удержание Esc или обеих кнопок мыши две секунды. Кнопка «Стоп» есть во вкладках RMFish. STOP-ETERNAL-CORE.bat отправляет мягкий сигнал; EMERGENCY-ETERNAL-CORE.bat сначала сигнализирует, затем принудительно завершает EternalCore.exe, не GTA5.exe. Если лоадер запущен от администратора, аварийному BAT тоже могут потребоваться права администратора. Если игру нельзя свернуть: Ctrl+Alt+Delete → Диспетчер задач → Подробности → завершить EternalCore.exe, не GTA5.exe. После принудительного завершения при необходимости нажмите и отпустите левую кнопку мыши.

При отзыве подписки или блокировке серверная проверка запрашивает остановку, а при потере связи — примерно через 90 секунд без подтверждения. Системный вызов, который уже завис, нельзя прервать мягкой остановкой. Не оставляйте бота без присмотра: обязательный лимит сессии по умолчанию — 120 секунд.

Подготовка рыбалки выполняется вручную: I/Ш → бамбуковая удочка → «Ловить рыбу» → «Хлебный мякиш». RMFish ищет светлый крючок и узкую светло-зелёную часть шкалы. Краткое перекрытие цели допускается только после её подтверждения в двух недавних кадрах той же полосы и только при видимом крючке. Быстрый крючок может проскочить между кадрами. Реальные GTA5, физическая клавиатура и поведение игры при блокировке ввода не проверены. Проверьте правила игрового сервера. Старые самостоятельные версии RMFish и исходный код остаются доступными; это не защищённая от модификации DRM.

По выбранной владельцем схеме HTTP в локальной сети логин, пароль, токены и ключи передаются БЕЗ ШИФРОВАНИЯ. Используйте только доверенную изолированную сеть. Для публичного доступа требуется HTTPS.

Для совместимости с прошлой версией сессия хранится в %LOCALAPPDATA%\RMacro\session.dat, настройки RMFish — в %LOCALAPPDATA%\RMFish\settings.ini. «Выйти из аккаунта» удаляет сохранённую сессию на этом ПК. При смене серверного адреса потребуется новый вход: старый токен на другой адрес не передаётся. Для смены устройства или после переустановки Windows обратитесь к администратору для сброса HWID. Нужны Windows 10/11, .NET Framework 4.5 или новее и доступный сервер. Сервер в клиентский архив не входит.
