# v0.1.0-beta.1 — Skyrim RP fishing (предварительный релиз)

Первый публичный релиз Python-проекта для Windows. ZIP — **исходники, не EXE**: нужен Python 3.10+ и зависимости из `requirements.txt`.

## Возможности

- Повторный заброс через инвентарь: TAB → ПКМ по удочке → верхнее «Использовать»; есть переключаемый заброс ЛКМ с удочкой в руках.
- OpenCV-анализ зелёной зоны, разноцветной рыбы, узкой полосы прогресса и красного предупреждения о срыве.
- Калибровка ROI, HSV-пипетка, предпросмотр, диагностические снимки и маски; опциональная проверка наживки по шаблону.
- F8 — toggle, F10 — аварийный стоп, Insert — окно, F9 — диагностика; настройки клавиш и порогов доступны из GUI.
- Отпускание мыши при остановке/потере фокуса, учёт уловов, срывов и неясных исходов.

## Установка

Распакуйте ZIP, выполните `pip install -r requirements.txt`, затем `python eternal_fishmod.py`. При игре с правами администратора запустите программу с теми же правами. Перед первым запуском автоматики прочтите раздел калибровки в `README.md` и проверьте координаты пункта **«Использовать»**, чтобы не выбрать «Выбросить».

## Известные ограничения

Это **beta/pre-release**: 12 автоматических тестов проходят (включая предоставленные снимки), но работа с настоящим окном игры, вводом SendInput и разными UI-scale не проверялась под Windows в этой среде. Первый цикл проведите под наблюдением с F10 под рукой. Таймер «рыба срывается» показывается как оценка от первого обнаруженного кадра, не OCR; исчезновение шкалы без подтверждённых 100% прогресса фиксируется как неопределённый исход.
