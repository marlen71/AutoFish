## [1.3.1] - 2026-10-13

### Fixed
- **`start.bat` больше не выдаёт «... is not recognized as an internal or external command» и код 9009.**
  `cmd.exe` читает `.bat` побайтово и хранит смещения строк, а `wscript.exe` читает `.vbs` как ANSI:
  кириллица в комментариях/`echo` вместе с LF-переводами сдвигали смещения, и вместо команд
  выполнялись обрезки соседних строк. Файлы запуска переписаны чистым ASCII с CRLF (без BOM) —
  весь переведённый и цветной вывод остался на стороне `launch.py`, который с UTF-8 работает корректно.
- Добавлен `.gitattributes` (`*.bat` / `*.cmd` / `*.vbs` → `text eol=crlf`), чтобы проблема не
  возвращалась при клонировании с любой ОС; файл теперь попадает и в релизный архив.
- `start.bat`: интерпретатор ищется реальным прогоном `py -3` → `python` → `python3`
  (`-c "import sys"`), поэтому пустая заглушка `python` из Microsoft Store больше не приводит к 9009;
  запуск через `-X utf8`; проверка наличия `launch.py` рядом с `.bat`; `pause` только при ненулевом
  коде возврата; убран одиночный `!` из `echo` (его съедала delayed expansion).
- `start_admin.bat` больше не дублирует запуск, а делегирует `start.bat` (единая логика поиска Python
  и сообщений), подъём прав — `Start-Process -Verb RunAs` с `-ExecutionPolicy Bypass`.
- `start.vbs`: если `pythonw` нет, пробует `py -3w`; если и он не найден — показывает `MsgBox` с
  объяснением вместо тихого исчезновения процесса.
- `launch.py` не падает с `UnicodeEncodeError`, когда вывод перенаправлен в файл или в консоль с
  cp866/cp1251 (пиктограммы ✓ и 🖥): stdout/stderr переведены в `errors="replace"`.
- Релизная автоматизация больше не рапортует «успех», если архив не прикрепился: `scripts/release.py`
  и workflow `Release build` догружают zip с повторами и сверяются с фактическим списком ассетов
  (загрузка ассетов идёт на отдельный хост `uploads.github.com`, который умеет обрываться), а при
  неудаче печатают ссылку на исходники тега и готовую команду `gh release upload`.

### Added
- `tests/test_launcher_files.py` — офлайн-проверка «якорных» файлов запуска: только ASCII, ровно CRLF,
  без BOM; баланс `( ... )`; все `goto` ведут на существующие метки; `echo` без `< > & |` и одиночных
  `!`; флаги, которые `.bat`/`.vbs` передают лаунчеру, там действительно распознаны; собираемая в
  `.vbs` командная строка разбирается мини-интерпретатором.
- README §3.4 — почему файлы запуска только ASCII+CRLF и как лечить после «спасительного»
  пересохранения в редакторе; §12 — отдельная строка про код 9009.

## [1.3.0] - 2026-10-14

### Added
- **Захват экрана через DXGI Desktop Duplication** (`ScreenCapture`, новые разделы 4/4B):
  `dxcam` — основной и единственный путь захвата во всём приложении (мини-игра, поиск
  шаблонов в инвентаре, проверка наживки, контекстное меню, `F9`-снимок, живое превью
  страницы «Зрение»); `bettercam` поддерживается как альтернативный DXGI-бэкенд;
  `mss` — только автоматический аварийный резерв (RDP/кривый драйвер), о чём бот
  предупреждает в журнале и крупно показывает на странице «Зрение».
- **Видеопоток мини-игры**: `camera.start(target_fps=CFG["capture_fps"], video_mode=True)`
  с region-захватом только шкалы (120–144 к/с вместо ~250 тяжёлых `mss`-кадров),
  измерение фактического FPS и задержки кадра, диагностика в GUI.
- **ПИД-регулятор** (`PIDController`) вместо bang-bang логики: Kp/Ki/Kd + `bias`
  (дежурная скважность), анти-windup интеграла, мёртвая зона по ошибке,
  аварийный комплект коэффициентов `pid_em_*`.
- **ШИМ-управление бинарным входом (ЛКМ)**: выход ПИД = скважность `duty`
  внутри короткого окна `1/pwm_hz`; реализован и альтернативный режим
  `pid_mode = "hyst"` (порог с гистерезисом) — по умолчанию работает ШИМ.
- **Упреждение по скорости И ускорению рыбы** (двойной EMA-фильтр), точнее за счёт высокого FPS.
- **Универсальное распознавание рыбы**: не по 1–2 HSV-диапазонам, а по отклонению пикселей
  строки от медианы строки — работает для любых видов рыб; `fish_detect` позволяет
  вернуть старый HSV-путь (`hsv`) или объединить оба (`both`); `fish_thr` — порог чувствительности.
- **Детектор состояния «РЫБА СРЫВАЕТСЯ!»** по красной рамке вокруг шкалы (`slip_thr`,
  `bar_pad`) + автоматический переход в аварийный режим удержания.
- **Полная локализация интерфейса RU / EN / UA** (словарь `STRINGS`, функция `t()`),
  переключение языка на лету на странице «Настройки», ключ `CFG["lang"]`.
  Локализуются страницы, кнопки, журнал, тосты, текст состояния, пилюля-оверлей;
  технические идентификаторы (ключи конфига, имена шаблонов, хоткеи) не переводятся.
- **Лаунчер `launch.py`** (+ `start.bat`, `start_admin.bat`, `start.vbs`): проверка Python,
  автоустановка зависимостей, проверка/запрос прав администратора (UAC `runas`),
  запуск бота отдельным процессом, `--restart`, цветная консоль, переводимые сообщения.
- **Диагностика на странице «Зрение»**: активный бэкенд захвата, реальный FPS, задержка
  кадра, телеметрия ПИД (ошибка, скважность, P/I/D, режим «норма/авария», потеря зоны),
  мини-график ошибки и скважности.
- **Страница «Модули»**: степперы всех коэффициентов ПИДА (норма и авария), частоты ШИМ,
  лимита интеграла, мёртвой зоны, упреждения, порога распознавания рыбы и срыва.
- **Настройка `use_offset` степпером** на странице «Настройки»; ручные координаты
  `rod_click_pos` / `use_click_pos` по-прежнему приоритетнее авто-поиска.
- **Версионирование и релизы**: файл `VERSION`, `CHANGELOG.md`, `scripts/release.py`
  (semver-бамп + коммит + тег + GitHub Release с zip-архивом, через `gh` CLI или REST),
  workflow `.github/workflows/release.yml` (релиз по тегу `v*.*.*`), версия показывается
  в заголовке окна, в пилюле-оверлее и на страницах «Настройки»/«Зрение».

### Changed
- **Меню удочки**: клик по «Использовать» теперь ищется **над** красной строкой «Выбросить»
  (`context_menu_info()`), а не по смещению вниз от точки ПКМ; `use_offset` =
  `[dx, dy_up]` — подъём от верхней кромки красной строки.
- `capture_template()` переводит координаты курсора из логических в физические и
  масштабирует окно съёма (раньше снимок «ехал» при DPI ≠ 100%).
- Все обращения к захвату идут через единственный объект `ScreenCapture`;
  `grab()`/`grab_px()` оставлены как тонкие прокси (никаких прямых `mss.mss().grab()` вне резерва).
- `LOST_LIMIT` (35 кадров) заменён на `lost_ms` (по умолчанию 140 мс) — поведение
  больше не зависит от частоты кадров; `MAX_HOLD`/`forced_release`/`fish_timeout` вынесены в конфиг.
- Формат конфига: добавлен `cfg_version` (аддитивная миграция — старые значения сохраняются,
  новые ключи берутся из `DEFAULT_CFG`).

### Fixed
- Интерактивные виджеты GUI (`stepper`, `stepper_list`, `toggle`) не падают, если страницу успели
  перерисовать между кликом и обновлением (`App.safe_itemconfig`).
- `mouse_move_abs()` больше не зависит от DPI-масштаба Windows (физические размеры монитора).
- Съём шаблонов и координаты курсора согласованы с физическим разрешением экрана.
- Освобождение DXGI-ресурсов при выходе (`App.quit()`, `atexit`, `ScreenCapture.close()`),
  чтобы не было «залипшего» дубликатора после перезапуска.
