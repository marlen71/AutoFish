# Датасет для AI-зрения: как разметить и обучить свою модель

Бот поставляется БЕЗ игровой модели. Ниже — путь от твоих скриншотов до
`rod_detector.onnx`, который подключается за 5 минут (см. docs/AI_VISION.md §5).

## 1. Сбор кадров

1. Играй как обычно. При включённом «AI-наблюдении» бот сам складывает кадры
   моментов «не знаю, что это» в `diagnostics/snapshots/` — это готовый сырой
   материал. Дополнительно: F9 (снимок) и просто скриншоты (Win+Shift+S).
2. Нужны сцены: инвентарь (с удочкой и без), меню предмета, ожидание клёва,
   мини-игра, «рыба срывается», тосты уведомлений, переходы/загрузки.
3. Минимум для первого детектора: **150–300 кадров** (по 20–50 на класс).
4. РАЗМЕЩЕНИЕ в репо не обязательно: датасет большой, держи его локально или в
   отдельном репозитории (в основной коммитить нельзя — раздует).

## 2. Классы (реестр `ai/detector.py` / manifest.json)

| Класс | Что размечать |
|---|---|
| `inventory_window` | окно инвентаря целиком |
| `fishing_rod` | иконка удочки в слоте (любой скин/состояние) |
| `bait_icon` | стаки наживки |
| `item_icon` | прочие предметы (опционально) |
| `interaction_prompt` | подсказки «нажми G» и т.п. |
| `notification_panel` | тосты («Улов поднят…», «Вы упустили рыбу») |
| `minigame_bar` | шкала мини-игры |
| `minigame_fish` | значок рыбы на шкале |
| `unknown` | не размечать — это и есть «неизвестное» |

## 3. Разметка

Любой инструмент формата YOLO: [LabelImg](https://github.com/HumanSignal/labelImg),
CVAT, Roboflow (разметка локально, экспорт YOLO). Прямоугольники по объектам
выше. Тексты уведомлений для OCR размечать не нужно — RapidOCR читает сам.

## 4. Обучение (пример YOLOv8, CPU достаточно для мелких моделей)

```bash
pip install ultralytics
yolo detect train data=dataset.yaml model=yolov8n.pt imgsz=640 epochs=60
```

`dataset.yaml`: пути к train/val + имена классов В ТОМ ЖЕ ПОРЯДКЕ, что в
`classes` манифеста.

## 5. Экспорт модели: два готовых layout

**Простой путь (v1.26, так собрана комплектная модель):** экспортируй стандартный
YOLO ONNX — детектор сам поймёт его layout `"yolov8"`:

```python
from ultralytics import YOLO
YOLO("best.pt").export(format="onnx", imgsz=448, opset=12)
# выход [1, 4+C, N]: cx,cy,w,h в пикселях входа + C скоров (без obj)
```

В `ai/models/manifest.json` укажи `"layout": "yolov8"` — больше ничего не нужно:
адаптер сам транслирует координаты через letterbox, режет по порогу и делает NMS
(`ai/detector.py::_decode_yolov8`).

**Ручной путь — контракт `nms5`:** конвейер также ждёт выход `[1, M, 5+C]`:
строка `[cx, cy, w, h, obj, cls...]`, все значения после sigmoid, координаты —
доли входа. Практический путь — обёртка-экспорт:

## 6. Подключение

```bash
python - <<'PY'
import hashlib
print(hashlib.sha256(open("rod_detector.onnx","rb").read()).hexdigest())
PY
```

Кладёшь `rod_detector.onnx` в `ai/models/`, вписываешь в `manifest.json` имя,
sha256, размер входа, классы. На странице «AI-ЗРЕНИЕ»: режим «AI» или «Гибрид»,
«Перезапустить AI». Статус должен стать `running` (не `bad_checksum`).
